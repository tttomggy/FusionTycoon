# Fusion Tycoon store art

The icon and five thumbnails. No real player's avatar appears in any of them.
The characters are plain blocky rigs (a classic yellow/blue "noob" kid, a
masked thief) posed in Studio. The orbs are painted to match the in-game orb
(glass sphere, neon core, mutation shell, orbit ring with satellites). Every
background is a real capture of a night lab. `RESEARCH.md` explains why the art
looks this way.

## Upload (Creator Hub → your game → Configure)

**Icon:** `icon.png` (512 × 512). Roblox can't A/B test icons. Change the icon
only in the same update as other changes, and note the date.

**Thumbnails** (1920 × 1080, each under 3 MB). Upload all five and **activate
all five in Thumbnail Personalization**. Roblox then shows each one and moves
traffic to whichever keeps players.

| File | Hook | What it tests |
|---|---|---|
| `thumb1_fuse.jpg` | FUSE TO SECRET! (lead, put it first) | Is fusing the hook? |
| `thumb2_mutations.jpg` | RAINBOW ×12! | Collecting and rarity |
| `thumb3_steal.jpg` | STEAL THEIR ORBS! | Stealing. Watch early bounce: stealing unlocks at Rebirth 1 |
| `thumb4_lab.jpg` | MAX YOUR LAB! | The tycoon / idle crowd |
| `thumb5_voidmoon.jpg` | VOID MOON | Events. Swap in a new event image with each update |

All text sits in the top ~70% of each image. The bottom strip is kept clear,
because the player count covers it.

**Title:** `[🌈] Fusion Tycoon 🔮`. Change the bracketed emoji with each
update: [⚡] Power Surge, [🌙] Void Moon, [☄️] meteors, [🛡️] a heist update. Put
"OUT NOW: …" as the first line of the description.

**What to watch** (Analytics):
- Thumbnail Performance: QPTR together with playtime per play. High QPTR with
  short playtime means the image oversells.
- Home Recommendations: play-through rate and first-play bounce.
- Keep the winning thumbnail in every later test. Add 1–2 new images per update
  and don't touch the set between updates.
